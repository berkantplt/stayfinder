Çiçekliköy – İzmir - Birgi – Çakırağa Konağı – Ödemiş – Tire – Kent Tarihi Müzesi
Gece yolculuğumuzun ardından Egenin Köyleri Birgi Tire Şirince Seferihisar Urla Alaçatı Turu için sabah saatlerinde Çiçekliköy’de doğa ile iç içe kahvaltımızı alıyoruz. Kahvaltı molamız sonrası turumuzun ilk noktası Birgi’ye gidiyoruz. Anadolu Beylikler döneminde Aydın ve çevresinde kurulup oldukça etkili olan Aydınoğluları Beyliğinin yönetim yeri olan Birgi’yi keşfetmeye başlıyoruz. Aydınoğlu Mehmet Bey Camii, İmam-ı Birgivi külliyesi, tarihi Çakırağa konağı, Umur Bey anıtı, Derviş Ağa (Çukur) Medresesi ve Hamamı göreceğimiz başlıca yerler olacaktır. Bunların yanında sokaklarda dolaşırken sizleri alıp başka zaman dilimine götürecektir. Birgi Köyü gezimizin ardından otobüsümüze geçerek Ödemiş ilçesini panoramik olarak görüp Türkiye’nin en güzel on kasabası arasında yer alan Tire’ye hareket ediyoruz. Hititler döneminden itibaren kesintisiz iskan edilmiş ve İlyada Destanında Homeros’un bahsettiği batı Anadolu'daki önemli yerleşim Tire’ye varıyoruz. Tire; Kültür ve doğa rotası olan, ünü ülke geneline yayılmış olan pazarı Beylikler ve Osmanlı döneminden kalma yapıları, lezzetli mutfağı ile bizleri karşılıyor. Tire’de Kent Tarihi Müzesi, Tire pazarı, Tire hanları, Yalınayak hamamı, Necip Paşa kütüphanesi gibi yapıları görebilir, Tire sokaklarında yolculuk yapıp lezzetlerinden tadabilirsiniz. Serbest zamanımızın ardından otelimize doru hareket ediyoruz. Akşam yemeği ve konaklama otelimizde.
Sabah Kahvaltısı: Çiçekliköy’de alınacaktır. (Ekstra)
Öğle Yemeği: Birgi’de alınacaktır. (Ekstra)
Akşam Yemeği: Otelde alınacaktır. Tur ücretine dâhildir.
Konaklama : İzmir/ 4* - 5* İzmir Otelleri

Kuşadası – Dilek Yarımadası Milli Parkı - Doğanbey Köyü - Şirince
Egenin Köyleri Birgi Tire Şirince Seferihisar Urla Alaçatı Turu 3. gününde otelde alacağımız kahvaltının ardından otobüsümüze binerek Kuşadası sınırlarında yer alan Dilek Yarımadası Milli Parkı sınırları içerisinde kurulmuş olan Doğanbey Köyü’ne gidiyoruz. Milli parka ait müzeyi gezip köy sokaklarında keşfe başlıyoruz. Yakın zamanda çekilen Dedemin Fişi, Entel Köy Efe Köye Karşı filmlerinin de çekildiği köy sokakları kendisine hayran bırakacaktır. binerek son gezi noktamız Türkiye’nin en estetik köylerinden biri olan Şirince’ye doğru hareket ediyoruz. Zeytinlikler arasında devam eden yolculuğumuz ile eski adı Çirkince olan Şirince’ye varıyoruz. İlk olarak bölgenin en nefis meyveli şaraplarının bulunduğu Şarap Evi’ni ziyaret ediyoruz. Daha sonra rehberimizin köy hakkında vereceği bilgilerin ardından köyde serbest zaman veriyoruz. Bu serbest zaman sırasında kumda kahve içerek köyün keyfini çıkarabilir veya köy içerisinde dolaşarak fotoğraflar çekip, hediyelik eşya alışverişi yapabilirsiniz. Serbest zamanımızın bitiminin ardından bu şirin köye veda ediyoruz. Otobüsümüzde buluşup otelimize doğru hareket ediyoruz. Akşam yemeği ve konaklama otelimizde

Seferihisar – Sığacık – Urla - Germiyan Köyü - Barbaros Köyü - Bademler Köyü - Alaçatı – İstanbul
Egenin Köyleri Birgi Tire Şirince Seferihisar Urla Alaçatı Turu 4. Gününde otelde alacağımız kahvaltının ardından otobüsümüze binerek Türkiye’de ilk Sakin Şehir unvanını alan Seferihisar’a doğru hareket ediyoruz. Türkiye’nin ilk Cittaslow sakin şehir (2009) unvanını kazanmış sahil kasabası Seferihisar'da, pek çok dizi ve filmin çekildiği Sığacık’a varıyoruz.
Kanuni Sultan Süleyman tarafından inşa ettirilmiş Osmanlı Kalesi’ni ve İç Kale’deki orijinal yapısını kaybetmemiş evleri görüyor, sokaklarında dolaşıyoruz. Kale içerisinde kurulan üretici pazarında alışveriş için serbest zaman veriyoruz. Ardından Türkiye’nin ilk köy tiyatrosunun kurulduğu Urla Bademler Köyü’ne gidiyoruz. Köy İzmir’in ve hatta Türkiye’nin en değerli köylerinden biri. Doğasıyla, taş evleriyle ve yöresel ürünlerin sergilendiği pazar alanıyla farklı bir atmosfer sunacaktır. Köy gezimiz sonrası aracımıza geçip Urla’ya geçiyoruz. Urla da ünlü şair, yazar Necati Cumalı Evi’ni ziyaret ediyoruz. Daha sonra Rum Evleri’nden oluşan Sanat Sokağı’ndan geçerken farklı bir zaman dilimine geçiyoruz.
Urlalı kadınların kooperatif kurup ürettikleri ürünlerini pazarladıkları Urlalı Kadın Üretici Pazarı’na gidip alışveriş için serbest zaman veriyoruz. Daha sonra Türkiye’nin ilk Oyuk Festivali’nin (Korkuluk) düzenlendiği Barbaros Köyü’ne gidiyoruz. Festival harici köye ayrı bir istihdam ve cazibe kattığı için korkuluklar artık köyün sakini olmuş durumdalar. Köy sokaklarında korkuluklar eşliğinde gezerken yaratıcı düşünce ve sokaklara kattığı farklılıktan kendinizi alamayacaksınız. Korkulukları geride bırakıp Türkiye’deki Slow Food hareketine katılan tek köy olan Germiyan Köyüne gidiyoruz.
Germiyan Köyünde Çiçek motifleri ile bezenmiş sokaklarda güzel manzaralar yakalamak için serbest zaman veriyoruz. Serbest zamanımızın ardından otobüsümüze binerek bir sonraki durağımız olan Alaçatı’ya hareket ediyoruz. Dar ve Arnavut kaldırım taşları üzerine kurulu, Rum mimarisi ile Osmanlı mimarisinin birleştiği renkli sokaklara sahip Alaçatı bizleri kendisine hayran bırakacaktır. Alaçatı sokaklarında rehberimizin belirleyeceği saate kadar serbest zaman veriyoruz. Serbest zaman sırasında Alaçatı sokaklarında tarihi taş evleri önünde renkli fotoğraflar çekerek turu unutulmaz hale getirebilirsiniz. Serbest zamanımızın bitmesiyle beraber Egenin Köyleri Birgi Tire Şirince Seferihisar Urla Alaçatı Turumuzun sonuna geliyor ve aracımıza geçip dönüş yolculuğuna başlıyoruz. Siz değerli misafirlerimizi aldığımız noktalara bırakıp, bir başka Malitur organizasyonunda buluşmak üzere siz değerli misafirlerimiz ile vedalaşıyoruz.

Önemli Notlar
• Tur süresi hareket ve dönüş günü dahil olmak üzere 3 Gece 4 Gün olup 2 gece otel konaklamalıdır. 1 gece yolculuk sürmektedir.
• Turumuzda rehberlik, ulaşım, konaklama ve çevre gezileri bir paket halindedir ve ayrı düşünülemez. Kullanılmayan ulaşım, konaklama, rehberlik, çevre geziler vb. haklar geri iade edilemez.
• Tur paketlerinde uygulanan çocuk indirimleri 2 yetişkin yanında tek bir çocuk için kullanılır. 0-6 yaş çocuklarda otel konaklamasında ayrı yatak verilmeyebilir.
• Otel konaklamalarında 3 kişilik odalarda 3. Misafirimiz genellikle ek yatakta konaklama sağlamaktadır.
• Programda belirtilen oteller Malitur’un öncelikli konaklama tesisleridir. Konaklanacak bölge ve otellerde yoğunluğa göre otel standartları aynı kalmak şartıyla değişiklik yapılabilir. Müsaitlikler doğrultusunda otel isimleri turun kalkışından 48 saat öncesinde talep edilmesi durumunda bildirilecektir.
• Kalınacak otellerdeki odalar otel tarafından belirlenmektedir. Odalar arasında seçim yapılamamaktadır.
• Mola yerlerimiz yoğunluk, tadilat vb. gibi mücbir sebeplerden ötürü mevkii ve hizmet standartları açısından aynı kalmak kaydıyla değiştirilebilir.
• Program zamanlamasında (gün içerisinde gezilecek noktaların sırasında veya günler arasında) hava durumu, yol durumu, ziyaret yerlerindeki yoğunluk vb. gibi durumlarda rehber gerekli gördüğü takdirde değişiklik yapabilir.
• Turumuzda mücbir sebeplerden dolayı (hava, yol, ziyaret yerlerindeki yoğunluk vb.) veya misafirlerin tur sırasında rehberimizin verdiği zamanlamalara uymamaları halinde tur programında yazdığı halde gezilemeyen yerlerden Malitur sorumlu değildir. Böyle bir durumda misafirin hak talebi doğmaz.
• Tüm turlarımızda kademeli fiyat sistemi uygulanmaktadır. Paket turun içerisindeki rezervasyon sayısının yükselmesi ve tarihin yaklaşması ile tur fiyatları da kademeli olarak artış gösterebilir. Malitur fiyatları arttırma hakkını saklı tutar. Bu durumda ön ödeme almadan fiyat sabitleme yapılamamaktadır.
• Rezervasyon sırasında kesinlikle koltuk numarası sözü ve garantisi verilemez. Rezervasyona girilen notların bir garantisi yoktur. En ön veya en arka gibi özel koltuk seçimi yapılmamaktadır.
• Araç içerisindeki koltuk düzeni Malitur Operasyonu tarafından rezervasyon sırası göz önüne alınarak ayarlanmaktadır. Koltuk yerleşimi konusundaki itiraz durumlarında ödeme iadesi mümkün değildir. Araçlarımızın tüm koltukları aynı standartlardadır.
• Tur programında yer alan gece turları gibi ekstra turlar kişi sayısı ve mevcut personelin şartlarına bağlı olarak gerçekleşir. Yol üzerinde yapılacak olan ekstra turlar tüm misafirlerin katılımı olmasa dahi gerçekleştirilecektir. Ekstra turlarda tur katılmayacak misafirlerimizi rehberimizin tarafından dinlenme alanlarına veya şehir merkezlerine yönlendirilecektir. Ekstra turlara katılmayan misafirler mola yerinde beklemeyi kabul ederek tura katılmışlardır.
• Ekstra bir turun herhangi bir sebeple gerçekleşmemesi halinde misafirin herhangi bir hak talebi doğmaz. Malitur’un bu durumda bir sorumluluğu yoktur.
• Ekstra tur fiyatları dönemlere göre değişebilir. Böyle bir durumda misafirin turu satın aldığı tarih değil, turun hareket ettiği tarih dikkate alınır. Tura gidilen dönemdeki ekstra tur fiyatı geçerli olur. Misafir bunu kabul ederek turu satın almıştır.
• Ulaşım aracı, otel, yeme-içme alanları ve tedarikçiler tarafından sağlanan bütün hizmetlerde misafir tarafından meydana gelebilecek maddi zararlardan Malitur sorumlu değildir. İşletmeler misafir tarafından meydana gelen maddi zararları talep etme hakkına sahiptir.
• 18 yaş altı reşit sayılmayan çocukların anne veya babalarından biri veya ikisi ile beraber katılmadığı durumlarda, tura katılım için gerekli olan muvafakatname seyahat sırasında kişilerin yanında bulundurulması zorunludur.
•Tur katılan misafirlerimiz sağlık sorunları, hamilelik durumu, sürekli kullanımda bulundukları ilaçlar ile ilgili raporları yanlarında bulundurmaları gerekmektedir.
• Kalkış noktaları için belirlenen saatlerde trafik, kaza vb. gibi rötar durumlarında gecikmeler yaşanabilir.
• Tur bitiminde varılacak saatler ile alakalı bilgiler tahmini olup, mücbir sebeplerle gelişecek gecikmelerden Malitur sorumlu değildir.
• Misafirlerimizi tur bitiminde aldığımız durakların karşı istikametinde indirilecektir. Farklı bir noktada inmek için araç personellerine lütfen ısrarcı olmayınız.
• Trafik kanunu gereği araçta bulunan tüm misafirlerimiz seyahatleri boyunca emniyet kemeri takması zorunlu olup, aksi haldeki durumlarda Malitur sorumlu değildir.
• Araç içerisinde bulunan kişisel tüm eşyaların sorumluluğu mola vb. yerlerde misafire aittir.
• İlk gün gezi otele girmeden başlayacağı için yanınızda bulundurmanız gereken eşyalarınızı ayrı bir şekilde hazırlayınız.
• Tur esnasında program yoğunluğundan dolayı bankamatik, döviz bürosu vs. yerler bulmak her zaman mümkün olmadığından dolayı hazırlıklı olunmasında yarar vardır.
• Gerçekleştirilecek programlar içerisinde uzun yollar kat edilebilir. Gerekli bilgilendirme tur rehberi tarafından araç içerisinde yapılacaktır.
• Öğle yemekleri yöreye özgü ekonomik menüler oluşturulmuştur. Öğle ve akşam yemeklerinde bölge yoğunluğuna bağlı olarak gruplara ayrılan masalar kullanılır.
• Turlarımızın başlangıç ve bitiş rotası bölge yoğunluğuna göre belirlenmektedir. Turumuz başlamadan kesinleşmiş rota başlangıç ve bitişini, misafirlerimiz diledikleri takdirde 2 gün öncesinde iletişime geçerek öğrenebilirler.
• Acenta tarafından tur yeterli sayıya ulaşamadığı durumlarda, misafire bilgi verilerek misafirin isteğine göre tur bir sonraki tarihe ertelenebilir veya iptal edilebilir. Ya da en yakın hareket noktasına biletleme yapılarak misafirin tura katılımı sağlanabilir. Böyle bir durumda Acenta misafirine üç (3) gün öncesinden arama, sms veya e-posta yoluyla bilgi vermekle yükümlüdür. Böyle bir durumda misafirin hak talebi hakkı doğmaz.
• Misafir tarafından hizmetin başlangıç tarihinden 30 gün önceye kadar sebep gösterilmeksizin yapılan iptal ve değişiklik işlemlerinde ödediği bedel misafire iade edilir. Tur tarihinden 29 ile 15 gün arasında yapılan iptal ve değişiklik işlemlerinde rezervasyon bedelinin %30’una; 15-7 gün arasında yapılan iptal ve değişiklik işlemlerinde rezervasyon bedelinin %50’sine; 7 Gün ve daha az sürede yapılan iptal ve değişiklik işlemlerinde rezervasyon bedelinin %100’üne kesinti uygulanır.
• İptal, İade ve Güvence Paketi satın alan misafirlerimiz sebep belirtmeksizin satın aldığı paket turu, tur başlangıç tarihinden 72 saat öncesine kadar kesintisiz olarak iptal edebilmektedir. İptal İade ve Güvence Paketi uçak biletlerini kapsamamaktadır.
• Müze Kart ve müze ören yeri girişleri tur ücretine dahil değildir. Tüm müze girişleri misafirler tarafından ödenir.
İPTAL İADE VE GÜVENCE PAKETİ
İptal İade ve Güvence Paketi, misafirin satın almış olduğu paket turu, tur başlangıç tarihinden 72 saat öncesine kadar hiçbir neden belirtmeksizin iptal ve değişiklik yapabilmesine olanak verir. İptal sonrasında ödemiş olduğu paket tur ücretinin tamamı hiçbir kesinti yapılmadan, ödeme şekline göre iade yapılır. İptal İade ve Güvence Paketi uçaklı turlarda uçak ulaşımını kapsamamaktadır. Bu paketi almak isteyen misafirlerimiz rezervasyon sırasında ekstra olarak rezervasyonlarına ekleme yaparak satın alabilirler.
1618 NOLU ZORUNLU SEYAHAT SİGORTASI
1618 nolu Zorunlu Seyahat Sigortası kapsamı Acentenin iflası veya herhangi bir nedenle paket tur hizmetinin verilmemesini kapsar. Tur ücretine dahildir. Sağlık sigortası değildir, tedavi masraflarını karşılamaz. Özel sağlık sigortası misafire ait harcamadır.

Merhaba sevgili yolculuk arkadaşım. Ben Ülkesel Profesyonel turist rehberi 4542 sicil numaralı Osman Usta. Bu programı seçmen için bazı önemli detayları listeledim. Umarım faydası olur. Turda görüşmek dileği ile…
Neden bu tura katılmalıyım?
Hafta sonu ve yoğun dönemlerde izin durumu ve geziye ayıracak az zamanı olanlar için ideal bir programdır. Kültürel açıdan oldukça zengin bir zamanların yönetim merkezleri olsun tarihi ticaret yollarının geçiş güzergahlarında bulunan sultanların padişahların danışmanlıgını yapan Alimler ve onların medreseleri hanları hamamları köşkleri villaları yaşam ve ticaret merkezleri olsun zamandaki yolculuklarını tamamlayıp günümüzde köy,kasaba,ilçe olarak siz kıymetli misafirlere kendi zamanlarının aşklarını sosyo kültürel ve ticari hayatını tüm çıplaklıgı ve sadeliği ile tabiî ki muhteşem yöresel lezzetler eşliğinde İlk gece yolculuğunun ardından bölgeye ulaştıktan sonra her dakikası dolu dolu geçerek sizlere sunar
Hangi dönemlerde tercih etmeliyim?
12 ay boyunca devam eden bir programdır. Her mevsim ve haftanın ayrı bir çekiciliği oluyor.
Program zamanlaması nasıl?
Otele girişler 18.00 ve otelden ayrılış 8:00 civarıdır otellerimiz İzmir merkeze yakın olduğundan akşam kendi programınızı yapıp İzmir’de sizi bekleyen gece hayatın tadına da bakabilirsiniz
Program yoğunluğu nedir?
Program yoğunluğu gün içerisinde belirtilen yerlerin gezisi fazla yoğun olmamakla birlikte gece yolculuğundan dolayı ilk gün birazcık yoruluyorsunuz ama akşamında otelde rahat yatağınız sizi bekliyor olacak.
Bizi neler bekliyor?
Konaklara işlenmiş aşkın kaybolmaya yüz tutmuş sanatların yaşatılma çabası doğal ve yöresel lezzetler,hanlar,hamamlar,medreseler,türbeler,camiler,çarşılar,sehirden köye göçen hayatları,kaleler,şarap mahzenleri ve meyve şarapları,kiliseler Egenin en güzel doğası,köyleri Ege? const zoomOutBtn = container.querySelector(".zoom-out");
let scale = 1;
let minScale = 1;
let maxScale = 3;
let isDragging = false;
let startX, startY;
let translateX = 0,
translateY = 0;
let lastTranslateX = 0,
lastTranslateY = 0;
function updateTransform() {
let maxTranslateX = (svgElement.clientWidth * scale - container.clientWidth) / 2;
let maxTranslateY = (svgElement.clientHeight * scale - container.clientHeight) / 2;
translateX = Math.min(maxTranslateX, Math.max(-maxTranslateX, translateX));
translateY = Math.min(maxTranslateY, Math.max(-maxTranslateY, translateY));
svgElement.style.transform = `translate(${translateX}px, ${translateY}px) scale(${scale})`;
}
zoomInBtn.addEventListener("click", function () {
if (scale < maxScale) {
scale += 0.2;
updateTransform();
}
});
zoomOutBtn.addEventListener("click", function () {
if (scale > minScale) {
scale -= 0.2;
updateTransform();
}
});
// *** Mouse Sürükleme ***
svgContainer.addEventListener("mousedown", function (event) {
isDragging = true;
startX = event.clientX - lastTranslateX;
startY = event.clientY - lastTranslateY;
svgContainer.style.cursor = "grabbing";
});
document.addEventListener("mousemove", function (event) {
if (isDragging) {
translateX = event.clientX - startX;
translateY = event.clientY - startY;
updateTransform();
}
});
document.addEventListener("mouseup", function () {
isDragging = false;
lastTranslateX = translateX;
lastTranslateY = translateY;
svgContainer.style.cursor = "grab";
});
// *** Dokunmatik Sürükleme ***
svgContainer.addEventListener("touchstart", function (event) {
isDragging = true;
const touch = event.touches[0];
startX = touch.clientX - lastTranslateX;
startY = touch.clientY - lastTranslateY;
svgContainer.style.cursor = "grabbing";
});
svgContainer.addEventListener("touchmove", function (event) {
if (isDragging) {
const touch = event.touches[0];
translateX = touch.clientX - startX;
translateY = touch.clientY - startY;
updateTransform();
}
});
svgContainer.addEventListener("touchend", function () {
isDragging = false;
lastTranslateX = translateX;
lastTranslateY = translateY;
svgContainer.style.cursor = "grab";
});
});
});
