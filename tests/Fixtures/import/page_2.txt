Sivas –Gökmedrese – Sivas Ulu Cami - Kongre Binası – Kale Cami – Buruciye Medresesi – Çifte Minareli Medrese – Şifaiye Medresesi
09:00 Söğütlüçeşme Tren İstasyonu
09:29 Pendik Tren İstasyonu
10:21 İzmit Tren İstasyonu
Sivas Divriği Kemaliye Elazığ Erzincan Ovacık Munzur Turumuz için sabah saatlerinde Söğütlüçeşme ve Pendik istasyonlarından yüksek hızlı trendeki yerimizi alıp unutulmaz yolculuğumuza başlıyoruz. Sabahın ilk saatlerinde başlayan bu yolculuk, sadece bir şehir değişimi değil; Anadolu’nun kalbine doğru yapılan anlamlı bir seyahatin başlangıcı oluyor. Yaklaşık altı buçuk saat sürecek konforlu ve keyifli yolculuk sonrası Cumhuriyet Kenti Sivas’a ulaşıyoruz. Aracımız ile buluştuktan sonra ayağımızın tozu ile gezimize başlıyoruz.
İlk olarak 1271 yılında yaptırılan Gök Medrese ’de rehberimizden alacağımız bilgiler ardından Ulu Cami’yi görüyoruz. Zamanla eğilen ve eğri olarak ayakta kalan minaresiyle ünlü Ulu Cami’yi gördükten sonra; Buruciye Medresesi, Çifte Minareli Medrese ve Şifaiye Medresesi ziyaretlerimiz ile Sivas Meydanı gezimize devam ediyoruz. Büyük Önder Mustafa Kemal Atatürk’ün “Biz Cumhuriyeti burada kurduk.” sözleriyle tarihe kazınan Sivas Kongre Binasını fotoğraflayıp anlamlı mekânı, Milli Mücadele’nin en kritik kararlarının alındığı bu tarihi atmosferi rehberimizin anlatımlarıyla birlikte hissediyoruz. Daha sonra Cumhuriyet Meydanında serbest zaman veriyoruz. Serbest zaman sırasında Madımak Otelini görebilir, Taşhan’da alışveriş yapabilir ve meşhur Çerkez’in Kahvesinde kahvelerinizi içebilirsiniz. Rehberimizin belirleyeceği saatte buluşup otelimize geçiyoruz. Akşam yemeği ve konaklama otelimizde

Kangal - Divriği Ulu Cami - Arapgir – Fırat Nehri – Karanlık Kanyon - Kemaliye – Mani Yol - Taş Yol – Lökhane - Elazığ
Sivas Divriği Kemaliye Elazığ Erzincan Ovacık Munzur Turumuz 2. gününde sabah otelde alacağımız kahvaltının ardından keyifli bir yolculuk ile Anadolu Arslanı olarak bilinen Kangal Köpeklerinin merkezi Kangal’a uğruyoruz. Güçlü ve çevik yapıları ve büyüklüğü ile dikkat çeken Kangallar hakkında bilgi alıp fotoğrafladıktan sonra Divriği’ye ulaşıyoruz.
13. yüzyıl Selçuklu Dönemi şaheseri olarak tanımlanan Divriği Ulu Camii ve Darüşşifasını gezerken mermerin sanata nasıl dönüştüğünü izleyeceğiz. İslam Mimarisinin bu başyapıtı UNESCO Dünya Miras Listesinde de yer almaktadır. (Restorasyon çalışmasının tamamlanması durumunda gezilecektir.) Divriği gezimiz sonrası Arapgir’e varıyoruz. Kerpiç ve taştan inşa edilmiş evleri sokakları, tarihi dokusu ve doğası ile kendisine hayran bırakacak Arapgir hakkında bilgi alıp panoramik gördükten sonra Recep Yazıcıoğlu Köprüsünden geçerek Kemaliye’ye ilerliyoruz. Yol güzergâhımızda Fırat Nehrinin oluşturduğu 100 metre derinliğe ulaşan Karanlık Kanyondaki yolculuğumuz sizi büyüleyecektir. Programın müsaitliği ve su seviyesinin uygunluğu durumunda dileyen misafirlerimiz ile Karanlık Kanyon Tekne Turu gerçekleştiriyoruz (Ekstra)
Gazi Mustafa Kemal Atatürk’ün “Eğinliler, siz kemale ermiş insanlarsınız. Bu yüzden adımı size veriyorum.” Demesi üzerine Kemaliye adını alan bu ilçede insanların elleriyle yaptığı Taş Yolu görüyoruz. Osmanlı Döneminde eşlerine özlem ve hasret dizeleri yazan kadınların sözlerinin sergilendiği Mani Yolunda yazılan manileri okuyarak yürüyoruz. Kemaliye çarşılarında Lök Tatlısı ve alışveriş için serbest zaman veriyoruz. Ardından otobüsümüze binerek Elâzığ’daki otelimize yolculuğumuz sonrası ulaşıyoruz. Akşam yemeği ve konaklama otelimizde.

Sivas Divriği Kemaliye Elazığ Erzincan Ovacık Munzur Turumuz 3. gününde sabah otelde alacağımız kahvaltının ardından Harput’ta kısa bir gezinti yaparak yaklaşık 3 bin yıllık tarihe sahip Harput Kalesi’ne neden Süt Kalesi denildiğini dinliyoruz. Ardından Doğu’nun Pisa Kulesi olarak adlandırılan Yatık Minaresi ile ünlü Harput Ulu Camii’ni ziyaret ediyoruz. Harput Tarihi Evlerini dışardan gördükten sonra Arap Baba Türbesini gidiyor ve rehberimizden Arap Baba’nın hikâyesini dinliyoruz. Ardından Hoca Ahmet Yesevi'nin hocası olan Mansur Baba Türbesini ziyarete ediyoruz. Rehberimizden bilgiler aldıktan sonra Keban Barajı’nı geçmek için Elazığ Meşeli’den Tunceli Pertek’e geçmek için feribota biniyoruz. Baraj sayesinde ada görünümü kazanan Pertek Kalesi’ni panoramik görüp fotoğraflıyoruz. Pertek’te baraj suları altında kalmaktan kurtarılan Sungurbey ve Çelebi Ağa Cami’lerini görüp bilgi alıyoruz. Daha sonra Hozat üzerinden Ovacık’a doğru yolculuğumuza devam ediyoruz. Tunceli ilinin en düz sayılabilecek alanda kurulmuş Ovacık; etrafı dağlarla çevrili ova görünümündedir. Tunceli’den geçen Munzur Suyu bu ilçenin yakınlarından doğmaktadır. Doğal güzelliği, tarımsal alanların aktif kullanımı ve Munzur gözeleri ile binlerce turisti ağırlayan Ovacık’ta, Munzur Gözeleri ve Munzur Baba’yı ziyaret ettikten sonra serbest zaman veriyoruz. Munzur Vadisi’nin eşsiz güzelliği ile beraber yolculuğumuza devam edip Halvori suyunun çıkış noktası olan Halvori Gözelerini görüyoruz. Bitmesini istemeyeceğiniz görsel şölen sunan zengin flora fauna ve biyoçeşitliliğe sahip Munzur Vadisi’nin bitiminde Fatma Ana Makamını ziyaret edip vadi ile vedalaşıyoruz. Aracımız ile otelimize doğru hareket ediyoruz. Akşam yemeği ve konaklama otelimizde.

Munzur Dağları – Girlevik Şelalesi –Keşiş Dağı – Erzincan Tren garı – Erzincan Yeraltı Çarşısı – Erzincan Müzesi – Terzibaba Türbesi - İstanbul
Sivas Divriği Kemaliye Elazığ Erzincan Ovacık Munzur Turumuz 4. gününde sabah otelde alacağımız kahvaltının ardından Girlevik Şelalesine doğu yola çıkıyoruz. Erzincan’ın Çağlayan bölgesine yakın ve Munzur Dağlarından akan serin suların oluşturduğu muazzam görsellik sunan Girlevik Şelalesinde Suyun kayalara çarpışını dinlerken, Anadolu’nun yalnızca tarih değil, güçlü bir tabiat hafızası da taşıdığını hissedersiniz. Fotoğraf molalarımız ve kısa yürüyüşümüzün ardından aracımız ile buluşuyoruz. Erzincan merkeze yapacağımız yolculukta Keşiş Dağının olağan görkemi eşliğinde yolculuk ile Erzincan merkeze ulaşıyoruz. Vedaların, kavuşmaların ve sağlamlığın sembolü; Doğu Ekspresinin önemli duraklarından biri olan tarihi Erzincan Tren Garı’na ulaşıyoruz. Tarihi bina hakkanında bilgiler alıp fotoğrafladıktan sonra Erzincan Müzesi’ne hareket ediyoruz. Bölgede kurtarılan arkeolojik zengin eserlerin yanı sıra etnoğrafik sergi de sunan müze gezimizi gerçekleştiriyoruz. Ardından Meşhur Erzincan Döneri ve yöresel lezzetleri tatmak için serbest zaman veriyoruz. Serbest zamanımızın bitimi ile birlikte Sıradaki durağımız manevî bir eşik: Terzi Baba Türbesi Asıl adı Mehmet Vehbi olan ve halk arasında Terzi Baba olarak bilinen bu gönül insanı, Erzincan’ın en önemli manevî şahsiyetlerinden biridir.
Terzi Baba Türbesini ziyaret ettikten sonra şehir merkezine iniyor ve Erzincan’ın sosyal hayatına karışıyoruz. Modern şehir dokusunun altında konumlanan Erzincan Yeraltı Çarşısı alışveriş ve yerel ürünler için keyifli bir durak oluyor. Bakırcılardan hediyelik eşyalara, yöresel lezzetlerden küçük esnaf dükkânlarına kadar pek çok seçenek burada bir arada. Serbest zamanın ardından aracımız ile Erzincan Yıldırım Akbulut Havalimanına doğru yolculuğa başlıyoruz. Havalimanında unutulmaz Sivas Divriği Kemaliye Elazığ Erzincan Ovacık Munzur Turumuzun sonuna geliyor bir başka Malitur organizasyonunda buluşmak üzere vedalaşıyoruz.

Önemli Notlar
• Turumuzda rehberlik, ulaşım, konaklama ve çevre gezileri bir paket halindedir ve ayrı düşünülemez. Kullanılmayan ulaşım, konaklama, rehberlik, çevre geziler vb. haklar geri iade edilemez.
• Tur paketlerinde uygulanan çocuk indirimleri 2 yetişkin yanında tek bir çocuk için kullanılır. 0-6 yaş çocuklarda otel konaklamasında ayrı yatak verilmeyebilir.
• Otel konaklamalarında 3 kişilik odalarda 3. Misafirimiz genellikle ek yatakta konaklama sağlamaktadır.
• Programda belirtilen oteller Malitur’un öncelikli konaklama tesisleridir. Konaklanacak bölge ve otellerde yoğunluğa göre otel standartları aynı kalmak şartıyla değişiklik yapılabilir. Müsaitlikler doğrultusunda otel isimleri turun kalkışından 48 saat öncesinde talep edilmesi durumunda bildirilecektir.
• Kalınacak otellerdeki odalar otel tarafından belirlenmektedir. Odalar arasında seçim yapılamamaktadır.
• Mola yerlerimiz yoğunluk, tadilat vb. gibi mücbir sebeplerden ötürü mevkii ve hizmet standartları açısından aynı kalmak kaydıyla değiştirilebilir.
• Program zamanlamasında (gün içerisinde gezilecek noktaların sırasında veya günler arasında) hava durumu, yol durumu, ziyaret yerlerindeki yoğunluk vb. gibi durumlarda rehber gerekli gördüğü takdirde değişiklik yapabilir.
• Turumuzda mücbir sebeplerden dolayı (hava, yol, ziyaret yerlerindeki yoğunluk vb.) veya misafirlerin tur sırasında rehberimizin verdiği zamanlamalara uymamaları halinde tur programında yazdığı halde gezilemeyen yerlerden Malitur sorumlu değildir. Böyle bir durumda misafirin hak talebi doğmaz.
• Uçaklı turlarımızda bölge havalimanlarında tur programında bulunan gezi noktalarını etkilemeyecek şekilde değişiklik yapılabilir. Böyle bir değişiklik durumunda Malitur tarafından uçak biletleri ile birlikte misafire bilgi verilecektir. Havalimanı değişikliği ile ilgili programda bir eksiklik olmadığı takdirde misafirin herhangi bir hak talebi doğmaz.
• Uçaklı turlarımızda hava muhalefeti veya havayolundan kaynaklı oluşacak rötarlardan dolayı programdaki aksamalardan Malitur sorumlu değildir. Böyle bir durumda misafirin hak talebi doğmaz.
• Uçaklı turlarımızda havayolu firması tarafından sefer saatlerinde yapılacak değişikliklerden Malitur sorumlu değildir. Sefer saati değişikliği Malitur tarafından misafire bilgi verilecektir.
• Tüm turlarımızda kademeli fiyat sistemi uygulanmaktadır. Paket turun içerisindeki rezervasyon sayısının yükselmesi ve tarihin yaklaşması ile tur fiyatları da kademeli olarak artış gösterebilir. Malitur fiyatları arttırma hakkını saklı tutar. Bu durumda ön ödeme almadan fiyat sabitleme yapılamamaktadır.
• Rezervasyon sırasında kesinlikle koltuk numarası sözü ve garantisi verilemez. Rezervasyona girilen notların bir garantisi yoktur. En ön veya en arka gibi özel koltuk seçimi yapılmamaktadır.
• Araç içerisindeki koltuk düzeni Malitur Operasyonu tarafından rezervasyon sırası göz önüne alınarak ayarlanmaktadır. Koltuk yerleşimi konusundaki itiraz durumlarında ödeme iadesi mümkün değildir. Araçlarımızın tüm koltukları aynı standartlardadır.
• Tur programında yer alan gece turları gibi ekstra turlar kişi sayısı ve mevcut personelin şartlarına bağlı olarak gerçekleşir. Yol üzerinde yapılacak olan ekstra turlar tüm misafirlerin katılımı olmasa dahi gerçekleştirilecektir. Ekstra turlarda tur katılmayacak misafirlerimizi rehberimizin tarafından dinlenme alanlarına veya şehir merkezlerine yönlendirilecektir. Ekstra turlara katılmayan misafirler mola yerinde beklemeyi kabul ederek tura katılmışlardır.
• Ekstra bir turun herhangi bir sebeple gerçekleşmemesi halinde misafirin herhangi bir hak talebi doğmaz. Malitur’un bu durumda bir sorumluluğu yoktur.
• Ekstra tur fiyatları dönemlere göre değişebilir. Böyle bir durumda misafirin turu satın aldığı tarih değil, turun hareket ettiği tarih dikkate alınır. Tura gidilen dönemdeki ekstra tur fiyatı geçerli olur. Misafir bunu kabul ederek turu satın almıştır.

İPTAL İADE VE GÜVENCE PAKETİ
İptal İade ve Güvence Paketi, misafirin satın almış olduğu paket turu, tur başlangıç tarihinden 72 saat öncesine kadar hiçbir neden belirtmeksizin iptal ve değişiklik yapabilmesine olanak verir. İptal sonrasında ödemiş olduğu paket tur ücretinin tamamı hiçbir kesinti yapılmadan, ödeme şekline göre iade yapılır. İptal İade ve Güvence Paketi uçaklı turlarda uçak ulaşımını kapsamamaktadır. Bu paketi almak isteyen misafirlerimiz rezervasyon sırasında ekstra olarak rezervasyonlarına ekleme yaparak satın alabilirler.

Neden bu tura katılmalıyım?
Bir yandan tren seyahati ile birbirinden güzel manzaralara şahit olup, Ata köklerimizin yeşerdiği kadim topraklara ayak basmak, Seçuklu döneminin dünyaca ünlü eserleri görmek , “Orda bir köy var uzakta, gezmesekte tozmasakta" diyen şairimiz Ahmet Kutsi Tecer in özlem duyduğu memleketini tanımak için gelmelisin ey gezgin.
Hangi dönemlerde tercih etmeliyim?
Kış biter sezonu başlar, kış başlar sezonu biter. Tüm yaz ve bahar ayları gezmeye müsaittir sen yeter ki mevsime göre giyin gel.
Program yoğunluğu nedir?
Orta yoğunlukta bir program, hangi yaş grubunda olursan ol bu turdan çok büyük keyif alacağından emin olabilirsin.
Bizi neler bekliyor?
Önce muhteşem bir tren yolculuğu, sonra iklimin her mevsim ayrı güzellikler sunduğu dağlar, ovalar ve tertemiz bir hava. Sonra objektiflerini sınırsız doyuracağın fotoğraflar ve ruhunu doyuracağın ve belki de kimliğini yeniden keşfedeceğin tarih serüveni. Yöresel hayvanlardan elde edilen ürünlerle şenlenen masalar da cabası.
MüzeKart gerekli mi?
Evet. Tur boyunca birçok ören yeri ve müze ziyaretinde MüzeKart gereklidir.

let scale = 1;

let startX, startY;

let lastTranslateX = 0,
lastTranslateY = 0;
function updateTransform() {
let maxTranslateX = (svgElement.clientWidth * scale - container.clientWidth) / 2;
let maxTranslateY = (svgElement.clientHeight * scale - container.clientHeight) / 2;
translateX = Math.min(maxTranslateX, Math.max(-maxTranslateX, translateX));
translateY = Math.min(maxTranslateY, Math.max(-maxTranslateY, translateY));
svgElement.style.transform = `translate(${translateX}px, ${translateY}px) scale(${scale})`;
}
zoomInBtn.addEventListener("click", function () {
if (scale < maxScale) {
scale += 0.2;
updateTransform();
}
});
zoomOutBtn.addEventListener("click", function () {
if (scale > minScale) {
scale -= 0.2;
updateTransform();
}
});
// *** Mouse Sürükleme ***
svgContainer.addEventListener("mousedown", function (event) {
isDragging = true;
startX = event.clientX - lastTranslateX;
startY = event.clientY - lastTranslateY;
svgContainer.style.cursor = "grabbing";
});
document.addEventListener("mousemove", function (event) {
if (isDragging) {
translateX = event.clientX - startX;
translateY = event.clientY - startY;
updateTransform();
}
});
document.addEventListener("mouseup", function () {
isDragging = false;
lastTranslateX = translateX;
lastTranslateY = translateY;
svgContainer.style.cursor = "grab";
});
// *** Dokunmatik Sürükleme ***
svgContainer.addEventListener("touchstart", function (event) {
isDragging = true;
const touch = event.touches[0];
startX = touch.clientX - lastTranslateX;
startY = touch.clientY - lastTranslateY;
svgContainer.style.cursor = "grabbing";
});
svgContainer.addEventListener("touchmove", function (event) {
if (isDragging) {
const touch = event.touches[0];
translateX = touch.clientX - startX;
translateY = touch.clientY - startY;
updateTransform();
}
});
svgContainer.addEventListener("touchend", function () {
isDragging = false;
lastTranslateX = translateX;
lastTranslateY = translateY;
svgContainer.style.cursor = "grab";
});
});
